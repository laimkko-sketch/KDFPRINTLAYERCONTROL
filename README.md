# KDFPRINTLAYERCONTROL · 인쇄지 샘플 보관대장

KDF | UNIDECO 인쇄지 패턴(KW·KS·KG)의 마스터샘플·로트샘플을 지관 단위로 보관하고, 보관 위치·입고·판정 이력을 관리하는 웹앱입니다.

**웹주소:** https://laimkko-sketch.github.io/KDFPRINTLAYERCONTROL/

## 주요 기능
- **위치도** — 현장 랙 실측 구성(ㄷ자 랙 왼쪽 면 R01~R05, 단 A~ / 지관 2단 쌓기) 지관 단면 시각화, 잔량재고 전용 RACK(RS)
  - 랙 표기: `R01 (KTE)`, `R04 M.T (공용)` · 위치 표기: `R04-C-12` (랙-단-지관번호)
  - 개발샘플(주황) · 양산샘플(파랑) · 반출중(테두리) · 폐패턴 검토(회색 줄무늬, 24개월 무입고) · 잔량재고(청록)
- **입고 등록** — 코드·입고일·인쇄지 업체·ROLL/m·판정 입력
  - 신규 코드 → 마스터샘플 등록 + 30 m 분할(자사 3 · 보령공장 3 · 인쇄지 업체 3 · 잔량 21 → RS 보관)
  - 기존 코드 → 로트샘플, 지관당 마스터 1 + 최신 로트 4장 보관(초과 시 가장 오래된 로트 폐기)
- **로트 판정** — 마스터와 기준 로트 *사이* 범위(ΔE)로 합격 / 기타(로트구분 등) / 불합격 제안
- **입고일 기간 검색**, 목록, 입고 내역(일자별 소계), 코드 대장(KW/KS/KG-0001~9999)
- **엑셀 2종** — 위치도(시각화) · 명목척도(패턴목록/로트 이력/계열 집계/코드대장/잔량재고)
- 휴대폰 화면 지원(하단 탭바, 아래에서 올라오는 상세 시트)

## 데이터 보관
- 입력 데이터는 **사용 중인 브라우저(localStorage)** 에 저장됩니다.
- 화면 아래 **데이터 보관 → 백업 저장(.json)** 으로 정기 백업하고, 다른 기기에서는 **백업 불러오기** 로 옮기세요.
- 여러 사람이 같은 데이터를 실시간 공유하려면 별도 공용 저장소(Supabase 등) 연결이 필요합니다.
